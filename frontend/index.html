🆘 Help & Support

Explore IntelliDocs feature documentation, search FAQs, or submit a support request.

🔍
🚀 1. Getting Started with IntelliDocs ▼
IntelliDocs is an AI-powered document management system. The top Dashboard provides instant system counters, security health summaries, quick actions, and recent activity. Use the left sidebar to navigate between Documents, Upload, AI Suggestions, Duplicates, Organization, Sharing & Groups, Explorer Graph, Trash, and Help & Support.
📤 2. Uploading Documents & Automated Processing ▼
Navigate to Upload to drag-and-drop or select files (PDF, Word .docx, Text .txt, or scanned Images). IntelliDocs automatically extracts text, performs OCR for scanned images, classifies the content, detects sensitivity (Public, Internal, Confidential), and builds vector embeddings for semantic search.
💡 3. AI Classification & Suggestions Queue ▼
The AI Engine proposes document categorizations, subcategories, tags, folder placements, and sensitivity classifications. Open Suggestions to review proposals with AI confidence scores and reasoning evidence. You can batch Accept, Edit, Keep As-Is, or Reject proposals safely.
🔍 4. Search, Semantic Search & Autocomplete ▼
Use the top global search bar for instant autocomplete across filenames, tags, folders, and categories. In Documents, apply exact filter combinations (File Type, Category, Sensitivity, Folder). Semantic vector search understands conceptual meanings even when exact keywords differ.
👥 5. Duplicate & Near-Duplicate Detection ▼
IntelliDocs detects exact duplicates via SHA-256 hashes, visual image duplicates via perceptual hashing, and near-duplicates via LSH semantic similarity. Visit Duplicates to compare candidate files side-by-side and decide to Keep Both or Trash Candidate.
🌿 6. Document Versioning, Trash & Recovery ▼
Uploading an updated document automatically creates a new version linked to the parent chain (v1, v2, etc.). Deleting a document moves it to Trash for soft-deletion recovery. From Trash, you can Restore items back to your library or Permanently Purge them.
🤝 7. Direct User Sharing & Group Access ▼
Share documents directly with registered users or custom groups with granular permissions: READ (view/download), APPEND (upload new versions), or WRITE (edit metadata/versions). Active shares can be managed or revoked anytime.
🔒 8. Access Lock & Password Protection ▼
Protect highly sensitive documents with an Access Lock key. Keys are hashed securely with Argon2. Locked documents require entering the secret access key to generate a session unlock token (X-Access-Lock-Token) before viewing details or downloading.
🗺️ 9. Relationship & History Explorer ▼
The Explorer Graph visualizes node-edge relationships between documents, folders, categories, tags, versions, and shared users. Click nodes to inspect details, hover for rich AI summaries, select edges to see "Why Connected?", or view full chronological audit event timelines.
🛡️ 10. Multi-User Isolation, Security & Privacy ▼
IntelliDocs enforces strict server-side multi-user isolation. Users can only access documents they own or have explicit permission to read. Sensitive PII values are detected and classified automatically, and all major actions are recorded in immutable audit logs.
🌐 11. Offline Capabilities & Network Dependencies ▼
Core document storage, text extraction, OCR, duplicate indexing, access locks, and search operate locally on the server. Remote API integrations or web lookup features operate when network connectivity is available.
